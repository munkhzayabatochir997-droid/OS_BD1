# Manual — Sleeping Teaching Assistant
## 1. Хэрэглэгчийн заавар
**Зорилго:** TA, сандал, оюутны харилцааг алхамчилсан/хөдөлгөөнт байдлаар харуулна.
**Орчин:** Chrome/Firefox/Edge/Safari-ийн шинэ хувилбар.
**Нээх:** `src/sleeping_ta.html`-г давхар товшино.
**Оролт:** Сандал 1–10, оюутан 1–20, програмчлах дундаж 1–30 с, тусламж 1–15 с, seed, хурд 0.5–20x.
**Удирдлага:** Run эхлүүлнэ · Pause зогсооно · Step 1 с урагшлуулна · Reset параметрээр шинээр эхлүүлнэ.
**Тэмдэг:** 🟣 TA унтаж байна · 🟢 тусламж · 🟡 сандал дээр хүлээж байна · 🔵 програмчилж байна · 🔴 (логт) сандал дүүрэн тул буцсан.
**Жишээ 1:** 3 сандал, 8 оюутан, 6 с, 3 с → дараалал үүсэж, заримдаа дүүрнэ.
**Жишээ 2:** 10 сандал, 5 оюутан → TA ихэнхдээ унтана.
**Түгээмэл алдаа:** Мужаас гадуур/хоосон утга → улаан алдааны мэдээлэл гарна; засаад Reset дарна.

## 2. Operational заавар
```
git clone <repo-url> && cd F.CSM302_BD1_SleepingTA
gcc -Wall -pthread -o sleeping_ta src/sleeping_ta.c   # gcc 9+ , Linux/WSL/macOS
./sleeping_ta 3 6 4 2 3
```
Тестүүд: `tests/test_cases.md`. Known issues: C хувилбар бодит `sleep()` ашигладаг тул удаан; UI нь C-ийн логикийг дискрет симуляциар загварчилсан.
